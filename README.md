# FlatSearcher — моніторинг оголошень про продаж квартир

Сайт: https://gaspode3.github.io/FlatSearcher/

Щодня збирає оголошення з **OLX, DOM.RIA, rieltor.ua, mistechko.com, svitkvartyr.com** у межах ціни з `config.json` і показує їх на сайті:
фото (гортаються) і карта, ціна в $ і грн, деталі, опис, контакти, мітки
🏛 старий фонд · 🔨 під ремонт · 👤 власник · 📐 простора · 💸 вище бюджету · ⚠ апартаменти / будується.

На сайті: вибір міста й кількості кімнат (1 / 2 / 3 / 4+), вкладки «Не переглянуті», «⭐ Обрані», «Відхилені»,
кнопка «Поділитись» (WhatsApp, Telegram, Viber) і посилання на конкретну картку (`…/#id=код`).

## Як додати місто

У `config.json` → `cities` вже є Одеса й Хмельницький з `"enabled": false`. Поставте `true` і закомітьте — з наступного запуску на сайті з'явиться перемикач міст. Для нового міста скопіюйте блок і вкажіть назви міста в адресах майданчиків (OLX визначає місто автоматично за назвою).

## Запуск (≈10 хвилин)

1. **Створіть репозиторій** на GitHub (публічний — для безкоштовних GitHub Pages) і завантажте туди вміст цієї папки:
   ```bash
   git init && git add . && git commit -m "Старт"
   git branch -M main
   git remote add origin https://github.com/<ваш-логін>/kvartyra-lviv.git
   git push -u origin main
   ```
2. **Увімкніть сайт:** Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/docs` → Save.
   За хвилину сайт буде на `https://<ваш-логін>.github.io/kvartyra-lviv/`.
3. **Дозвольте Actions записувати дані:** Settings → Actions → General → Workflow permissions → *Read and write permissions* → Save.
4. **(Рекомендовано) Ключ DOM.RIA API:** зареєструйтесь на <https://developers.ria.com> **з відповідями на додаткові питання** (так дають 1000 запитів на місяць замість 100), отримайте ключ і додайте його: Settings → Secrets and variables → Actions → New repository secret, назва `DOMRIA_API_KEY`.
   (Поки що DOM.RIA збирається з HTML-сторінок; ключ API — запасний варіант.) Збирач витрачає ліміт ощадливо: 1 пошуковий запит на день і запит деталей лише для нових оголошень, не більше 25 за запуск (`api_info_per_run` у `config.json`). Разом це до ~800 запитів на місяць. Без ключа збирач розбирає HTML-сторінки DOM.RIA — це працює, але менш надійно.
5. **Перший запуск:** вкладка Actions → «Пошук квартир» → *Run workflow*. Далі він запускатиметься сам щодня о 07:17.

## Сповіщення

Коли з'являються нові варіанти, бот створює issue «🏠 Нові квартири ДД.ММ» зі списком і посиланнями. GitHub надсилає про це лист і пуш у застосунку GitHub Mobile (якщо ви «дивитесь» репозиторій — для власних це так за замовчуванням).

## Як змінити критерії

Усе в `config.json`: кількість кімнат, бюджет, межа ціни, з якої площі квартира вважається «просторою», кількість сторінок пошуку. Відстань від центру не обмежується.

Мітки (старий фонд, під ремонт тощо) ставляться за ключовими словами в описі — регулярні вирази на початку `scraper/scrape.py` (`OLD_FUND_RE`, `REPAIR_RE`, …). Доповнюйте, якщо щось пропускає.

## Якщо щось перестало збиратися

Сайти час від часу змінюють верстку. Помилки збору видно у верхньому рядку сайту і в лозі Actions.
Локально:
```bash
pip install -r requirements.txt
python scraper/scrape.py --debug   # збереже сирі сторінки в debug/
```
OLX розбирається з JSON-стану сторінки (`window.__PRERENDERED_STATE__`), із запасним розбором карток. DOM.RIA — через API або HTML.

## Обмеження

- Статуси («Дивився», «Відхилено») і нотатки зберігаються в браузері, тобто окремо на кожному пристрої.
- LUN не збирається: на ньому немає прямих посилань на оголошення, а більшість його оголошень дублює OLX і DOM.RIA.
- Варіанти з позначкою «Вручну» додані під час першого пошуку. Частина з них веде на сторінку будинку на LUN, а не на саме оголошення.
